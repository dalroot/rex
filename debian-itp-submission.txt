Description     : REX (Remote EXecution Protocol) daemon for AI Agents

 REX is an agent-native infrastructure control layer that enables AI agents
 to securely observe, manage, and operate remote machines without terminal
 dependency. Features include sub-5ms execution latency, 3 security tiers
 (autonomous, review, allowlist), persistent WebSockets, and structured JSON frames.

This package is intended to be maintained within the Debian Go Packaging Team.
